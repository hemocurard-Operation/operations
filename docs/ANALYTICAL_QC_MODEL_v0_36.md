# Modelo de Calidad Analítica

MÉTODO
→ VERIFICACIÓN / VALIDACIÓN
→ APROBACIÓN
→ PLAN IQC
→ RESULTADO QC
→ ACEPTADO / FUERA CONTROL
→ INVESTIGACIÓN
→ DESVIACIÓN
→ NC / CAPA
→ VERIFICACIÓN DE EFECTIVIDAD

EQA / PT
→ PROGRAMA
→ EVENTO
→ ENVÍO
→ RESULTADO
→ SATISFACTORIO / NO SATISFACTORIO
→ INVESTIGACIÓN
→ NC / CAPA

El motor IQC inicial usa límites configurados y un z-score simple cuando existe media y DE.
No implementa reglas complejas de forma automática sin validación del laboratorio.
