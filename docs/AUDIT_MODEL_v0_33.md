# Modelo de Auditoría Interna

PROGRAMA ANUAL
→ AUDITORÍA
→ CRITERIOS
→ MUESTREO / EVIDENCIA
→ HALLAZGO
→ OBS / OPORTUNIDAD / NC
→ NC formal
→ CAPA
→ verificación
→ cierre

Control de independencia:
el auditor líder no puede ser el propietario del proceso auditado.

Tipos de evidencia:
DOCUMENTO, REGISTRO, ENTREVISTA, OBSERVACION, MUESTRA, FOTO, OTRO.
