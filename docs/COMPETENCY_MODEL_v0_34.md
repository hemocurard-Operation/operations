# Modelo de Competencias

PUESTO
→ COMPETENCIAS REQUERIDAS
→ NIVEL REQUERIDO
→ CAPACITACIÓN
→ EVALUACIÓN
→ EVIDENCIA
→ RESULTADO
→ VIGENCIA
→ ALERTA / BRECHA
→ ACCIÓN

Estados calculados:
- SIN_EVALUAR
- BRECHA
- SUPERVISION
- VENCIDA
- POR_VENCER
- COMPETENTE

La capacitación por sí sola no equivale a competencia demostrada.
