# Códigos de diagnóstico HemoCura v0.30

## Configuración
- CONFIG_OK
- CONFIG_URL_EMPTY
- CONFIG_URL_INVALID
- CONFIG_URL_HOST
- CONFIG_URL_PATH
- CONFIG_KEY_EMPTY
- CONFIG_KEY_FORMAT
- CONFIG_SECRET_KEY
- CONFIG_APP_BASE_INVALID

## Red / Supabase
- NETWORK_FAILED
- SUPABASE_UNREACHABLE

## Auth
- AUTH_INVALID_CREDENTIALS
- AUTH_EMAIL_NOT_CONFIRMED
- AUTH_FAILED
- SESSION_MISSING

## Acceso
- PROFILE_MISSING
- ROLE_MISSING
- PERMISSION_MISSING
- RLS_DENIED

## Base de datos
- TABLE_MISSING
- VIEW_MISSING
- RPC_MISSING
- COLUMN_MISSING
- MIGRATION_MISSING

## Frontend
- FRONTEND_FILE_MISSING
- FRONTEND_IMPORT_FAILED
- APP_ERROR

Cada diagnóstico debe incluir: código, subsistema, mensaje, detalle técnico cuando exista y acción sugerida.
