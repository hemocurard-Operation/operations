# HemoCura v0.26.0

## Instalación
1. Subir SAFE PATCH sobre v0.25.0.
2. Ejecutar `sql/26_COMMAND_CENTER_DAILY_CLOSE_v0_26.sql`.
3. Abrir #command.
4. Revisar scorecard.
5. Crear una excepción de prueba.
6. Crear una acción.
7. Ejecutar cierre diario de una sucursal.
8. Revisar conciliación.
9. Ejecutar #qa.

## Modelo gerencial
Datos → excepción → responsable → acción → fecha → evidencia → cierre.
