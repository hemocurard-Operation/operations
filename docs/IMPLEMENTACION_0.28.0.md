# HemoCura v0.28.0

## Instalación
1. Confirmar que el `js/config.js` actual funciona.
2. Subir SAFE PATCH v0.28.0.
3. Ejecutar `sql/28_DEPLOYMENT_GOVERNANCE_v0_28.sql`.
4. Abrir `/deployment-check.html`.
5. Iniciar sesión.
6. Abrir `#releasegate`.
7. Corregir cualquier ERROR/NOT READY.
8. Ejecutar `#qa`.

## Importante
El paquete NO incluye `js/config.js`.
No lo cree de nuevo si ya existe en GitHub.
