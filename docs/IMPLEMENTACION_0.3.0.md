3. Subir/reemplazar:
   - index.html
   - css/app.css
   - js/app.js
   - js/login.js
   - hemocura-core/bootstrap.js
   - hemocura-core/layout.js
   - hemocura-core/router.js
   - hemocura-core/views.js

4. Abrir `/operations/`.
5. Debe mostrar menú lateral y Dashboard.
6. Probar cada opción de menú.
7. Probar recarga en una ruta hash.
