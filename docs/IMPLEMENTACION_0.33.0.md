# HemoCura v0.33.0

## Instalación
1. Subir SAFE PATCH sobre v0.32.1.
2. NO tocar `js/config.js`.
3. Ejecutar `sql/33_INTERNAL_AUDITS_v0_33.sql`.
4. Cerrar sesión y volver a iniciar.
5. Abrir `#internalaudits`.
6. Crear programa anual.
7. Crear auditoría y validar independencia del auditor.
8. Configurar criterios.
9. Registrar hallazgos/evidencia mediante Supabase o próxima UI detallada.
10. Convertir una NC de auditoría en `nonconformities`.
11. Crear CAPA si procede.
12. Revisar `#qmsgov`, `#audit`, `#diagnostics`, `#releasegate` y `#qa`.
