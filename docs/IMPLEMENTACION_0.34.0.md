# HemoCura v0.34.0

## Instalación
1. Subir SAFE PATCH sobre v0.33.0.
2. NO tocar `js/config.js`.
3. Ejecutar `sql/34_COMPETENCY_TRAINING_v0_34.sql`.
4. Cerrar sesión y volver a iniciar.
5. Abrir `#competencies`.
6. Crear puestos y competencias.
7. Vincular competencias obligatorias a puestos.
8. Asignar puestos a perfiles.
9. Registrar evaluaciones.
10. Revisar brechas, vencimientos y cumplimiento.
11. Vincular hallazgos de auditoría con competencias cuando proceda.
12. Ejecutar `#diagnostics`, `#releasegate` y `#qa`.
