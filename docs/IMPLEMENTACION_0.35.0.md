# HemoCura v0.35.0

## Instalación
1. Subir SAFE PATCH sobre v0.34.0.
2. NO tocar `js/config.js`.
3. Ejecutar `sql/35_RESOURCES_CONTROL_v0_35.sql`.
4. Cerrar sesión y volver a iniciar.
5. Abrir `#resources`.
6. Registrar equipos críticos.
7. Configurar próximas fechas de mantenimiento/calibración.
8. Registrar reactivos/lotes y su verificación.
9. Crear puntos ambientales y registrar lecturas.
10. Revisar alertas.
11. Vincular desviaciones relevantes con NC/CAPA.
12. Ejecutar `#diagnostics`, `#releasegate` y `#qa`.
