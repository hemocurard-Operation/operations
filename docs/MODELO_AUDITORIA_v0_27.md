# Modelo de Auditoría

Eventos auditados:
- liberación de unidades;
- creación/actualización de cierres;
- creación/actualización de excepciones;
- creación/actualización de acciones.

Cadena:
evento → usuario → sucursal → entidad → antes/después → fecha/hora.

La aplicación no expone funciones de borrado de bitácora.
