# Modelo explicable

Demanda diaria = unidades despachadas / días observados.
Cobertura = inventario disponible / demanda diaria 30d.
Necesidad = objetivo + stock de seguridad - disponible.
Donantes requeridos = necesidad / rendimiento promedio validado por donación efectiva.

Si el rendimiento está en REQUIERE_VALIDACION, la estimación se muestra pero no debe tratarse como parámetro aprobado.
