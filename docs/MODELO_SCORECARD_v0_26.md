# Scorecard gerencial

Puntaje inicial = 100.
Penalizaciones explicables:
- stock rojo: -10 c/u;
- alerta crítica/alta del flujo: -8 c/u;
- excepción crítica abierta: -15 c/u;
- acción SGC abierta: -3 c/u, máximo 10 acciones en la penalización.

Semáforo:
- VERDE >= 85
- AMARILLO >= 70
- ROJO < 70

Este score es un indicador gerencial, no clínico.
