# Flujo QMS v0.32

## Documento
BORRADOR / EN_REVISION
→ Solicitud DOCUMENT_APPROVAL
→ Aprobador distinto
→ APROBADA
→ Ejecución
→ document_register.status = APROBADO
→ document_changes = APROBADO
→ auditoría

## CAPA
ABIERTA / EN_CURSO
→ verificar efectividad
→ effectiveness_status = EFECTIVA o VERIFICADA
→ Solicitud CAPA_CLOSE
→ aprobación
→ ejecución
→ status = CERRADA
→ closed_at / closed_by
→ auditoría

La aprobación no sustituye el análisis técnico ni la evidencia de efectividad.
