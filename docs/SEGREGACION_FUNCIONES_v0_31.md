# Segregación de funciones

Modelo recomendado:
1. Solicitante prepara la acción.
2. Aprobador revisa y decide.
3. Ejecutor realiza la acción aprobada.
4. Auditoría conserva solicitud, decisión, usuario, fecha y resultado.

Controles:
- solicitante ≠ aprobador cuando la política lo exige;
- para acciones soportadas, solicitante ≠ ejecutor;
- roles autorizados por política;
- declaración de conformidad obligatoria;
- registro de auditoría.

La "firma operativa" del sistema es un registro de responsabilidad interna.
No debe presentarse como firma digital cualificada salvo que exista la infraestructura y el marco jurídico correspondiente.
